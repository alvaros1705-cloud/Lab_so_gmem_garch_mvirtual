# Neon Cyber Lab — Sistemas Operativos

Versión recuperada y validada de la guía interactiva bilingüe.

## Contenido
- 17 actividades de laboratorio
- Selector Español / English con banderas SVG
- Sección “Antes de comenzar” bilingüe
- Cinco módulos independientes y navegación a sus actividades
- Comandos copiables, cuestionarios y simuladores
- Caja de herramientas, cierre y descarga de notas
- Diseño responsive para computador, tableta y móvil

## Uso
Abre `index.html` en un navegador moderno. Para publicar, reemplaza el `index.html` del repositorio de GitHub Pages por este archivo.
